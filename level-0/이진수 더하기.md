### 문제 설명

이진수를 의미하는 두 개의 문자열 bin1과 bin2가 매개변수로 주어질 때, 두 이진수의 합을 return하도록 solution 함수를 완성해주세요.

제한사항
return 값은 이진수를 의미하는 문자열입니다.
1 ≤ bin1, bin2의 길이 ≤ 10
bin1과 bin2는 0과 1로만 이루어져 있습니다.
bin1과 bin2는 "0"을 제외하고 0으로 시작하지 않습니다.
입출력 예
bin1 bin2 result
"10" "11" "101"
"1001" "1111" "11000"
입출력 예 설명
입출력 예 #1

10 + 11 = 101 이므로 "101" 을 return합니다.
입출력 예 #2

1001 + 1111 = 11000 이므로 "11000"을 return합니다.

### 문제 풀이

```cpp
#include <string>
#include <vector>
#include <cmath>
#include <algorithm>
#include <iostream>

using namespace std;

string return_bin(int bi) {
    string answer = "";

    if(bi == 0) {
        return "0";
    }
    while(bi > 0) {
        answer += to_string(bi % 2);
        bi /= 2;
    }

    reverse(answer.begin(), answer.end());
    return answer;
}

string solution(string bin1, string bin2) {
    string answer = "";

    int temp_bin1 = 0;
    int temp_bin2 = 0;

    reverse(bin1.begin(), bin1.end());
    reverse(bin2.begin(), bin2.end());

    for(int i = 0; i < bin1.size(); i++) {
        int t = pow(2,i);
        if(bin1[i] == '1') {
            temp_bin1 += t;
        }
    }

    for(int i = 0; i < bin2.size(); i++) {
        int t = pow(2,i);
        if(bin2[i] == '1') {
            temp_bin2 += t;
        }
    }

    answer = return_bin(temp_bin1 + temp_bin2);

    return answer;
}
```
